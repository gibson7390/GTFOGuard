Implement the GTFOGuard terminal UI layer.

Current architecture:

ProcessCollector
→ Detectors
→ Engine
→ RiskScorer

The UI must consume the scored output produced by Engine.

Goal:

Create the first analyst-facing interface for GTFOGuard.

Requirements:

1. The UI must be presentation-only.
2. The UI must contain zero detection logic.
3. The UI must contain zero scoring logic.
4. The UI must never inspect process behavior to make security decisions.
5. The UI only renders scored results it receives.

Architecture constraints:

GOOD:

Engine.run()
→ List[RiskScore]
→ UI.render(results)

BAD:

if "/tmp/" in exe:
if "bash -c" in cmdline:
if score > 5 because path is suspicious

All security decisions must remain in detectors and RiskScorer.

UI requirements:

Use the existing Rich dependency.

Render detections in a professional terminal table.

Columns:

- PID
- User
- Binary
- Detection Type
- Severity
- Score
- Explanation

Display severity visually using Rich styling.

Provide clean handling for:

- zero detections
- one detection
- many detections

The UI must be readable in a normal terminal window.

Code style requirements:

- Production-quality Python
- Small focused files
- Self-explanatory names
- No AI-style banner comments
- No placeholder comments
- No decorative ASCII art
- No tutorial-style comments
- Use comments only when explaining non-obvious implementation decisions

Validation requirements:

1. Validate with real Engine output.
2. Validate with synthetic LOW, MEDIUM, and HIGH detections.
3. Demonstrate empty-state rendering.
4. Demonstrate table rendering with multiple severities.
5. Show exact console output.

Restrictions:

- No ancestry detector
- No correlation engine
- No monitoring loop
- No configuration layer
- No detector rewrites
- No scoring rewrites
- No commits
- No pushes

Deliver:

1. Architecture summary
2. Files created/modified
3. Validation results
4. Exact console output
5. Any discovered tradeoffs

Implement only the UI layer.
